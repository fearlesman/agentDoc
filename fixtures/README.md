# fixtures：跨模块固定测试样例

本目录存放四人共用的 JSON 固定样例（fixture）。任何模块的测试都可以直接读取这里的文件，避免各自手写数据导致契约漂移。

## 约定的样例文件

| 文件 | 产生方 | 主要使用方 | 说明 |
| --- | --- | --- | --- |
| `document_ir.json` | A 文档解析 | B、C、D | 解析后的结构化文档，含 sections、blocks、tables、anchor |
| `checklist.json` | B 检查单 | B、C、D | 检查单与检查项，含 steps 与版本状态 |
| `checklist_match.json` | B 匹配 | C、D | 文档类型识别结果与候选检查单匹配 |
| `review.json` | B 审查 | C、D | 一次审查的结果，含 findings 与 summary |
| `job.json` | C 任务编排 | B、D | 异步任务状态与进度 |
| `decision.json` | D 复核 | C | 复核结论事件，含复核人、时间、意见 |
| `export.json` | C 导出 | D | 报告导出任务与产物信息 |
| `dataset_case.json` | 评测 | 全员 | 注入缺陷的评测用例与标注 |

## 规则

1. 文件名与契约章节中的对象名保持一致，一个文件只放一个顶层对象。
2. 所有 ID 使用固定值，不随机生成，保证测试可复现。
3. 时间统一使用带时区的 ISO 8601 格式，例如 `2026-11-20T10:00:00+08:00`。
4. 修改样例必须同步修改 `contracts/` 下的契约说明，并在提交信息中写明原因。
5. 样例中不得出现真实企业材料内容，只用脱敏或虚构数据。

## 校验

样例的字段、枚举和状态必须与 `contracts/最终统一数据契约v1.1.md` 一致。CI 会校验：

- JSON 可以被解析；
- 必填字段齐全；
- 枚举取值在允许集合内；
- ID 引用可以对应上；
- anchor 指向的段落编号存在；
- summary 的统计数字与 findings 重算结果一致。
